# OLX → Telegram: все чаты OLX в одном боте

Телеграм-бот, в который приходят сообщения покупателей **со всех ваших аккаунтов OLX**, и из которого на них можно **сразу отвечать** — ответ уходит в OLX от того же аккаунта, в тот же чат.

- 📥 Новые сообщения приходят через ~10 секунд после того, как покупатель их отправил.
- 🏷 Над каждым сообщением видно, **с какого аккаунта** оно пришло (цветная метка и название), по какому объявлению и от кого.
- ↩️ Ответ — обычным «ответить» (свайпом) в Telegram или кнопкой «Ответить».
- ➕ Аккаунтов OLX можно подключить **сколько угодно**, прямо из бота.
- 👥 Можно дать доступ сотрудникам: они тоже будут получать сообщения и отвечать.
- 🔒 Работает через **официальный API OLX**. Пароли от OLX бот не видит и не хранит.

## Как это выглядит

```
🟦 Автозапчасти Киев
📦 Фара передняя Toyota Camry 70
👤 Андрей

Добрый день, ещё в наличии? Отправите Новой почтой?

[ ↩️ Ответить ] [ 📜 Переписка ]
[ ✔️ Прочитано ]
```

Смахиваете сообщение влево → пишете «Да, в наличии, отправим сегодня» → бот отвечает «✅ Отправлено в OLX от 🟦 Автозапчасти Киев».

## Настройка (один раз, ~15 минут + ожидание одобрения от OLX)

### Шаг 1. Создайте Telegram-бота (2 минуты)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) → нажмите **Start** → отправьте `/newbot`.
2. Придумайте имя (например, `Мои чаты OLX`) и адрес, заканчивающийся на `bot` (например, `my_olx_chats_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH...`. Сохраните его — понадобится на шаге 3.

### Шаг 2. Получите ключи OLX API (5 минут + ожидание)

OLX пускает сторонние программы к сообщениям только через свой официальный API. Ключи получают **один раз** — они подходят для всех ваших аккаунтов.

1. Зайдите на [developer.olx.ua](https://developer.olx.ua) и войдите любым своим аккаунтом OLX.
2. Нажмите **«Підключити додаток»** (подключить приложение) и заполните форму. Назначение можно описать так: *«Бот для ответов на сообщения покупателей в Telegram для моих аккаунтов»*.
3. В поле **Redirect URI** (адрес перенаправления) впишите:
   ```
   https://example.com/
   ```
4. Дождитесь письма от OLX о подтверждении приложения (обычно от нескольких часов до пары дней).
5. После подтверждения в кабинете разработчика появятся **Client ID** и **Client Secret**. Их вы введёте прямо в боте.

> Пока ждёте одобрения, можно спокойно сделать шаг 3.

### Шаг 3. Запустите бота

Бот должен работать **круглосуточно**, иначе сообщения не будут приходить. Выберите один вариант:

#### Вариант А — на своём компьютере с Windows (проще всего попробовать)

1. Установите Python с [python.org/downloads](https://www.python.org/downloads/). В первом окне установщика **обязательно поставьте галочку «Add python.exe to PATH»**.
2. Распакуйте папку с ботом, например на рабочий стол.
3. Дважды щёлкните **`start.bat`**.
4. При первом запуске окно попросит токен из шага 1 — вставьте его (правый клик мышью) и нажмите Enter.
5. Появится надпись `✅ Бот работает`. **Не закрывайте это окно** — пока оно открыто, бот работает.

⚠️ Когда компьютер выключен или спит, сообщения не приходят (придут после включения — ничего не потеряется). Для работы 24/7 — вариант Б.

#### Вариант Б — на сервере, 24/7 (рекомендуется для постоянной работы)

Подойдёт любой недорогой VPS (≈ 4–5 $/мес, Ubuntu, 1 ГБ памяти — например, Hetzner, DigitalOcean, Contabo или любой украинский хостинг). Подключитесь к серверу по SSH и выполните:

```bash
# 1. Установить Docker (один раз)
curl -fsSL https://get.docker.com | sh

# 2. Загрузить папку с ботом на сервер (например, через WinSCP или git) и перейти в неё
cd olx-bot

# 3. Указать токен бота из шага 1
cp .env.example .env
nano .env            # впишите BOT_TOKEN=ваш_токен, сохраните: Ctrl+O, Enter, Ctrl+X

# 4. Запустить
docker compose up -d --build
```

Всё. Бот сам перезапускается после сбоев и перезагрузки сервера.
Посмотреть, что он делает: `docker compose logs -f` (выход — Ctrl+C).

### Шаг 4. Первый вход и ключи OLX

1. Откройте своего бота в Telegram (ссылка вида `t.me/my_olx_chats_bot`) и нажмите **Start**.
   **Первый, кто нажмёт Start, становится владельцем** — поэтому сделайте это сразу после запуска.
2. Бот попросит **Client ID** и **Client Secret** из шага 2 — пришлите их по очереди. Бот проверит ключи в OLX и удалит сообщение с секретом из переписки.

### Шаг 5. Подключите аккаунты OLX

Для каждого аккаунта:

1. Нажмите **«➕ Добавить аккаунт OLX»**.
2. Скопируйте ссылку из сообщения бота и откройте её **в браузере в режиме инкогнито** (на компьютере: `Ctrl+Shift+N` в Chrome). Это важно: так вы войдёте именно в нужный аккаунт, а не в тот, что уже открыт в браузере.
3. Войдите в аккаунт OLX (логин и пароль вводятся на самом сайте OLX) и нажмите **«Разрешить»**.
4. Откроется страница *example.com* — так и должно быть. Скопируйте **весь адрес из адресной строки** (в нём есть `code=...`) и отправьте его боту.
5. Бот ответит «✅ Аккаунт подключён» и покажет, сколько в нём чатов.

Повторите для остальных аккаунтов. Каждый получает свою цветную метку.
Старую переписку бот не пересылает, чтобы не завалить вас сообщениями, — приходят только новые. Старые непрочитанные чаты можно посмотреть кнопкой **«📬 Непрочитанные»**.

## Ежедневная работа

| Что сделать | Как |
|---|---|
| Ответить покупателю | Смахнуть его сообщение влево (или долгое нажатие → «Ответить») и написать текст. Либо кнопка **«↩️ Ответить»**. |
| Посмотреть всю переписку | Кнопка **«📜 Переписка»** под сообщением |
| Отметить прочитанным в OLX | Кнопка **«✔️ Прочитано»** (после вашего ответа чат отмечается прочитанным сам) |
| Все непрочитанные чаты | Кнопка меню **«📬 Непрочитанные»** |
| Переименовать аккаунт, поставить на паузу, удалить | **«📋 Мои аккаунты»** → выбрать аккаунт |
| Дать доступ сотруднику | **«⚙️ Настройки» → «👥 Сотрудники»** → переслать сотруднику ссылку-приглашение |

Если в бот написать текст **не ответом** на сообщение покупателя, он никуда не уйдёт — бот подскажет, как ответить. Так невозможно случайно отправить сообщение не тому человеку.

## Частые вопросы

**Бот прислал «⚠️ OLX отозвал доступ».**
Так бывает, если в аккаунте сменили пароль или нажали «выйти со всех устройств». Нажмите кнопку **«🔑 Переподключить»** под этим сообщением и повторите шаг 5 для этого аккаунта. Подключение обновится, метка и название сохранятся.

**Подключил не тот аккаунт.**
Значит, в браузере уже был открыт другой аккаунт OLX. Удалите лишний в «📋 Мои аккаунты» и подключите нужный через режим инкогнито.

**Бот пишет «OLX не принял код».**
Код одноразовый и действует несколько минут. Нажмите ссылку для входа ещё раз и сразу пришлите новый адрес.

**Можно ли отправить фото?**
Отправляются только текстовые ответы. Фото и файлы от покупателей приходят в бот ссылками «📎 Вложение».

**Сколько аккаунтов можно подключить?**
Сколько угодно. Бот проверяет все аккаунты параллельно.

**Сообщения приходят с задержкой?**
OLX не умеет сам сообщать о новых сообщениях, поэтому бот проверяет все аккаунты каждые 10 секунд. Интервал можно изменить в `.env` (`POLL_INTERVAL`), но меньше 10 секунд ставить не стоит.

**Как обновить бота или перенести на другой компьютер?**
Все данные (аккаунты, ключи, сотрудники) лежат в папке `data`. Скопируйте её вместе с файлом `.env` — и бот продолжит работу на новом месте без повторной настройки.

**Бот не отвечает.**
- Вариант А: проверьте, что окно `start.bat` открыто и компьютер не спит.
- Вариант Б: выполните на сервере `docker compose ps` (должно быть `running`) и `docker compose logs --tail 50`.

## Дополнительные настройки (`.env`, по желанию)

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | Токен бота (обязательно) |
| `OWNER_ID` | Ваш Telegram ID — если хотите, чтобы владельцем мог стать только этот человек |
| `OLX_CLIENT_ID`, `OLX_CLIENT_SECRET` | Ключи OLX API, если удобнее указать их здесь, а не в боте |
| `OLX_REDIRECT_URI` | Адрес перенаправления (по умолчанию `https://example.com/`, должен совпадать с указанным на developer.olx.ua) |
| `OLX_DOMAIN` | Страна OLX: `www.olx.ua` (по умолчанию), `www.olx.pl`, `www.olx.ro`, `www.olx.pt`, `www.olx.bg`, `www.olx.kz`, `www.olx.uz` |
| `POLL_INTERVAL` | Как часто проверять новые сообщения, секунд (по умолчанию 10) |

## Для разработчика

```
main.py            точка входа, первичный запрос токена
app/config.py      настройки из .env
app/db.py          SQLite: аккаунты, токены, состояние чатов, привязка сообщений Telegram ↔ OLX
app/olx.py         клиент OLX Partner API v2 (OAuth2, автообновление токенов)
app/poller.py      фоновый опрос аккаунтов, определение новых сообщений по total_count
app/services.py    доставка входящих в Telegram, ответы в OLX, история
app/handlers.py    диалоги бота (aiogram 3)
tests/             тесты логики и сквозной сценарий с фейковыми Telegram и OLX
```

Запуск тестов: `pip install -r requirements-dev.txt && pytest`.
